00. Tech Stack

Frontend Teknolojileri

Framework: ASP.NET Core MVC (.NET 8)

View Engine: Razor (cshtml)

CSS Framework: Bootstrap 5.3

JavaScript: Vanilla JS (gerektiginde)

Icons: Bootstrap Icons

IDE: Visual Studio 2026

Mimari Karar

Frontend: Ayri bir ASP.NET Core MVC projesi (HotelApp.Web)

Backend: Ayri bir ASP.NET Core Web API projesi (HotelApp.API)

Iletisim: MVC Controller'lar HttpClient ile API'yi cagirir

Auth: JWT token Session/Cookie'de tutulur

Neden MVC?

  • Kursta ogrenidigimiz yaklasim, proje notuna katkisi yuksek
  • _Layout.cshtml ile navbar/footer tek yerde yonetilir
  • Partial View'lar ile bilesenleri tekrar kullanabiliriz
  • Tag Helpers ile form validation temiz ve guvenli
  • Server-side rendering, JWT token tarayicida acikta durmaz

08. ApiService Yapisi

Tum API cagirilari tek bir servis uzerinden yapilir. DI ile Controller'lara inject edilir.

ApiService Sorumlukluklari

  • HttpClient ile Web API'ye istek gonderme (GET, POST, PUT, DELETE)
  • JWT token'i otomatik olarak Authorization header'ina ekleme
  • JSON serialization/deserialization
  • Hata yakalama ve anlamli mesaj donme
  • appsettings.json'dan API base URL okuma
// appsettings.json { "ApiSettings": { "BaseUrl": "https://localhost:7001/api" } } // IApiService.cs (Interface) Task<T> GetAsync<T>(string endpoint); Task<T> PostAsync<T>(string endpoint, object data); Task<T> PutAsync<T>(string endpoint, object data); Task<bool> DeleteAsync(string endpoint); // Kullanim ornegi (Controller icerisinde) var hotels = await _api.GetAsync<PagedResult<HotelDto>>("/hotels?page=1"); return View(hotels);

09. Authentication Akisi

Giris (Login) Akisi

1 Kullanici /Auth/Login sayfasini acar
2 Email + sifre girer, formu gonderir (POST)
3 AuthController.Login -> ApiService.PostAsync("/auth/login", loginDto)
4 API JWT token + kullanici bilgisi dondurur
5 Token HttpContext.Session'a kaydedilir
6 Kullanici ana sayfaya yonlendirilir

Korunakli Sayfa Erisimi

1 Kullanici /Reservations/My sayfasina gitmek ister
2 Custom AuthFilter session'da token var mi kontrol eder
3 Token yoksa -> /Auth/Login'e yonlendir
4 Token varsa -> ApiService istege token'i ekler
5 API 401 donerse -> session temizle, login'e yonlendir

Admin Sayfa Erisimi

1 Kullanici /Admin/Dashboard'a gitmek ister
2 AdminAuthFilter session'daki kullanici rolunu kontrol eder
3 Rol "Admin" degilse -> 403 Forbidden veya ana sayfaya yonlendir
4 Rol "Admin" ise -> sayfa normal render edilir

10. Rezervasyon Akisi

Rezervasyon islemi otel detay sayfasinda modal ile yapilir (ayri sayfa yok).

Rezervasyon Olusturma

1 Kullanici otel detay sayfasinda oda tiplerini gorur
2 Tarih ve misafir sayisi girerek musaitlik kontrolu yapar (E15)
3 Musait oda tiplerinden birinde "Rezerve Et" tiklar
4 Giris yapmamissa -> login sayfasina yonlendirilir, sonra geri gelir
5 Modal acilir: tarih, misafir, fiyat ozeti gosterilir
6 "Onayla" tiklar -> BookingController.Create (POST) -> E23
7 Basarili -> Rezervasyon detay sayfasina yonlendirilir
8 Hata (musait degil) -> modal'da hata mesaji gosterilir

11. Arama Akisi

Otel Arama

1 Ana sayfada sehir secilir, giris/cikis tarihi ve misafir sayisi girilir
2 "Ara" butonu tiklanir -> /Hotels/Search?city=X&checkIn=Y&checkOut=Z&guests=N
3 HotelsController.Search -> ApiService -> E07 cagirilir
4 Sonuclar otel kartlari olarak listelenir
5 Kullanici filtre uygular (yildiz) -> sayfa yeniden yuklenir
6 Otel kartina tiklanir -> /Hotels/Detail/5 sayfasina gider
