# Trello Ana Listeler

Kaynak:
- `trello ana liste açıklamaları.txt`

Bu dosya, Trello board üzerindeki ana kolonların ne işe yaradığını sade şekilde açıklar.

## 1. Backlog
Tüm görevlerin bulunduğu ana listedir.
Henüz başlanmamış işler burada tutulur.

Kısaca:
- Yapılacak işler deposu
- Henüz aktif değil
- Zamanı gelince sprint içine alınır

## 2. Sprint Backlog
O haftanın hedeflerini gösteren listedir.
Yani "bu hafta bunları yapacağız" denilen kartlar burada bulunur.

Kısaca:
- Haftalık hedef listesi
- Backlog'dan seçilen işler buraya gelir

## 3. In Progress
Şu anda aktif olarak üzerinde çalışılan işler burada olur.

Kısaca:
- Biri bu kart üzerinde çalışıyor
- İş devam ediyor

## 4. Review / PR
Kod yazılmıştır ama kontrol süreci devam ediyordur.
Genelde PR açılmış olur ve başka biri inceleme yapar.

Kısaca:
- Kod tamamlandı
- İnceleme bekliyor
- Onay süreci var

## 5. Testing
İş test aşamasına gelmiştir.
Çalışıyor mu, beklenen sonucu veriyor mu kontrol edilir.

Kısaca:
- Teknik test
- Hata kontrolü
- Son doğrulama

## 6. Done
İş tamamen bitmiştir.
Kart artık tamamlanmış kabul edilir.

Kısaca:
- Görev bitti
- Board üzerinde kapanmış iş anlamına gelir
