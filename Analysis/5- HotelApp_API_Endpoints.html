Auth Seviyesi

Genel Bilgiler

Base URL: https://localhost:7XXX/api/

Authentication: JWT Bearer Token. Giris yapildiktan sonra alinan token, korunakli endpoint'lere erisim icin Authorization: Bearer <token> header'i ile gonderilir.

Content-Type: Tum istek ve yanitlar application/json formatindadir.

Sayfalama: Liste endpoint'leri ?page=1&pageSize=10 query parametrelerini destekler. Varsayilan: page=1, pageSize=10, maksimum pageSize=50.

Yetkilendirme Seviyeleri

Anonymous Giris yapmadan herkes erisebilir.

[Authorize] Sadece giris yapmis kullanicilar erisebilir.

[Admin] Sadece Admin rolundeki kullanicilar erisebilir.

Standart Hata Yanit Formati

{
  "message": "Hata aciklamasi",
  "errors": ["Detayli hata 1", "Detayli hata 2"]
}

Sayfalamali Yanit Formati

{
  "items": [ ... ],
  "totalCount": 150,
  "page": 1,
  "pageSize": 10,
  "totalPages": 15
}

E01 POST /api/auth/register Anonymous
Yeni kullanici kaydi olusturur. Basarili kayit sonrasi JWT token dondurur.
Istek (UserRegisterDto)
Alan Tip Konum Zorunlu Aciklama
FirstName string Body Evet Kullanicinin adi. Maks 100 karakter.
LastName string Body Evet Kullanicinin soyadi. Maks 100 karakter.
Email string Body Evet E-posta adresi. Email formati zorunlu. Benzersiz olmali.
Password string Body Evet Sifre. Minimum 6 karakter.
Phone string Body Evet Telefon numarasi. Maks 20 karakter. Zorunludur.
Yanit (LoginResponseDto)
Alan Tip Aciklama
Token string JWT Bearer token. Sonraki isteklerde Authorization header'inda kullanilir.
User UserDto Kullanici bilgileri (Id, FirstName, LastName, Email, Phone, Roles).
HTTP Durum Kodlari
200 OK 400 Validation Hatasi 409 Email Zaten Kayitli
Is Kurallari
  • Email benzersiz olmali. Ayni email ile ikinci kayit 409 dondurur.
  • Sifre BCrypt ile hash'lenerek PasswordHash alanina kaydedilir. Duz metin olarak ASLA saklanmaz.
  • Varsayilan olarak "User" rolu atanir (UserRoles tablosuna eklenir).
  • IsActive=true olarak olusturulur. CreatedAt otomatik atanir.
