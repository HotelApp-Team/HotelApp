Sprint 1

Faz 1: Temel Altyapi -- "Projeyi Ayaga Kaldirma"

06 Nisan (Pzt) - 12 Nisan (Paz) | Kapasite: 45-60 kisi-saat

Kritik Sprint

Bu sprint tum projenin temelini atar. Burada yapilan isler olmadan hicbir grup kendi gorevine baslayamaz. 3 kisi birlikte calisir, ORTAK altyapi kurulur.

Birlikte Yapilacak (3 Kisi)

  • Gun 1 (Pzt): Kickoff toplantisi tamamlandi, grup atamalari yapildi, Trello board kurulumu yapildi
  • Gun 1 (Pzt): Git repo olusturma, branch stratejisi (main, dev, alper-dev, hilal-dev, sevde-dev)
  • Gun 1-2 (Pzt-Sal): SQL Script calistirma (12 tablo + SP + View + Trigger + Index + Seed data). Logs tablosu dahil (10 kolon, 3 Index, FK -> Users)
  • Gun 2 (Sal): Solution olusturma (4 Onion Architecture projesi, katman referanslari)
  • Gun 2 (Sal): Scaffold calistirma (EF Core DB First entity uretimi)
  • Gun 3 (Car): Program.cs konfigurasyonu (DI container, JWT ayarlari, CORS policy, Swagger)
  • Gun 3-4 (Car-Per): Temel JWT + AuthController (E01 Register, E02 Login) -- pair programming
  • Gun 4-5 (Per-Cum): _Layout.cshtml (public) + _AdminLayout.cshtml + Bootstrap entegrasyonu
  • Gun 5-6 (Cum-Cmt): ApiService (HttpClient wrapper) + AuthFilter + AdminFilter
  • Gun 6-7 (Cmt-Paz): _Pagination.cshtml (partial) + Swagger test + build kontrolu

Milestone 1 -- Sprint 1 Bitis Kriteri (12 Nisan)

[ ] Solution derleniyor (build basarili)

[ ] DB baglantisi calisiyor (Docker SQL Server)

[ ] Swagger UI aciliyor, AuthController gorunuyor

[ ] Register + Login API calisiyor, JWT token doniyor

[ ] MVC projesi aciliyor, Layout render ediliyor

[ ] ApiService ile API'ye istek atilabiliyor

[ ] Git repo'da dev, alper-dev, hilal-dev ve sevde-dev branch'leri hazir

Sprint 2

Faz 2a: Backend API -- "Paralel Gelistirme Baslar"

13 Nisan (Pzt) - 19 Nisan (Paz) | Kapasite: 45-60 kisi-saat

Gruplar kendi gelistirme branch'lerinde paralel calismaya baslar. Her grup kendi ozelliginin backend tarafini (Domain -> Infrastructure -> API) tamamlar.

Grup A: Kimlik + Yonetim Backend + Logger Singleton (~15-20 saat)

  • Domain: IAuthRepository, IUserRepository interface'leri tanimla, AuthService (JWT uretimi, email verify mantigi), UserService + DTO'lar (RegisterDto, LoginDto, TokenResponseDto, ProfileDto)
  • Domain: LogEntry.cs entity, LogDto.cs, ILoggerService.cs interface (Singleton pattern icin sozlesme)
  • Infrastructure: AuthRepository (BCrypt hash/verify), UserRepository implementasyonu
  • Infrastructure: LogRepository.cs -- Singleton implementasyonu (Private constructor + Lazy<T>, thread-safe, kisa omurlu DbContext)
  • API: AuthController tamamla -- E03 (profil), E42 (email verify), E43 (resend verification)
  • API: ExceptionLoggingMiddleware.cs -- global hata yakalama + LogError
  • API: Program.cs'e LogRepository.Initialize() + AddSingleton<ILoggerService> + UseMiddleware ekle
  • Infrastructure: EmailService (SMTP/Mailtrap -- calismassa mock, yedek plan aktif)

Grup B: Otel Vitrin Backend (~15-20 saat)

  • Domain: IHotelRepository, IHotelImageRepository, IAmenityRepository interface'leri, HotelService, HotelImageService, AmenityService + DTO'lar (HotelListDto, HotelDetailDto, HotelCreateDto, ImageDto, AmenityDto)
  • Infrastructure: HotelRepository, HotelImageRepository, AmenityRepository implementasyonu
  • API: HotelsController (E04-E10), HotelImagesController (E16-E19)
  • API: AmenitiesController (E32-E33), HotelAmenitiesController (E34-E35)

Grup C: Islemler Backend (~15-20 saat)

  • Domain: IRoomTypeRepository, IHotelRoomRepository interface'leri, RoomTypeService, HotelRoomService + DTO'lar (RoomTypeDto, HotelRoomDto, AvailabilityDto)
  • Infrastructure: RoomTypeRepository, HotelRoomRepository implementasyonu (SP cagrilari dahil)
  • API: RoomTypesController (E20-E22), HotelRoomsController (E11-E15)
  • DB Test: sp_SearchAvailableRooms stored procedure'unu farkli senaryolarla test et

Milestone 2 -- Sprint 2 Bitis Kriteri (19 Nisan)

[ ] Auth API tam calisiyor (register, login, profil, email verify)

[ ] Hotels CRUD API Swagger'da test ediliyor (liste, detay, ekle, guncelle, sil)

[ ] RoomTypes + HotelRooms API calisiyor, musait oda arama (SP) calisiyor

[ ] Gorsel yukleme/silme API calisiyor

[ ] Her grup kendi branch'inde, PR acilmis, Alper review etmis

[ ] Takim branch'lerinden gelen ilk merge'ler dev branch'inde kontrol edilmis, build basarili

Sprint 3

Faz 2b: Frontend Public + Kalan Backend

20 Nisan (Pzt) - 26 Nisan (Paz) | Kapasite: 45-60 kisi-saat

Backend API'ler hazir oldugundan, gruplar simdi kendi ozelliklerinin frontend tarafina geciyor. Bazi gruplar eksik backend islerini de tamamliyor.

Grup A: Auth Frontend (~15-20 saat)

  • MVC: AuthController -- Login.cshtml (giris formu + beni hatirla + hata mesajlari)
  • MVC: AuthController -- Register.cshtml (kayit formu + validasyon)
  • Partial: _LoginPartial.cshtml (navbar'da giris/cikis durumu)
  • MVC: ProfileController -- Index.cshtml (profil bilgileri goruntuleme)
  • Test: Login -> token alma -> session saklama -> profil goruntuleme akisini uctan uca test et

Grup B: Otel Frontend (~15-20 saat)

  • MVC: HomeController -- Index.cshtml (ana sayfa: arama formu + populer oteller)
  • MVC: HotelsController -- Search.cshtml (arama sonuclari + filtre + siralama + sayfalama)
  • MVC: HotelsController -- Detail.cshtml (otel detay: temel bilgiler, gorsel galeri bolumu)
  • Partial: _HotelCard.cshtml (otel kart componenti), _StarRating.cshtml (yildiz gosterimi)
  • Test: Ana sayfa -> arama -> sonuclar -> otel detay akisini uctan uca test et

Grup C: Rezervasyon + Yorum Backend (~15-20 saat)

  • Domain: IReservationRepository, IReviewRepository interface'leri, ReservationService, ReviewService + DTO'lar (ReservationCreateDto, ReservationDetailDto, ReviewDto)
  • Infrastructure: ReservationRepository (sp_MakeReservation dahil), ReviewRepository
  • API: ReservationsController (E23-E27: olustur, listele, detay, iptal, fatura)
  • API: ReviewsController (E28-E31: yaz, listele, sil, yorumlarim)
  • DB Test: sp_MakeReservation + trg_UpdateHotelRating calismasini dogrula

Milestone 3 -- Sprint 3 Bitis Kriteri (26 Nisan)

[ ] Login/Register sayfalari calisiyor, oturum yonetimi saglikli

[ ] Ana sayfa render ediliyor, populer oteller gorunuyor

[ ] Otel arama + filtreleme calisiyor, sonuclar sayfalaniyor

[ ] Otel detay sayfasinin temel yapisi goruluyor

[ ] Rezervasyon + Yorum API'leri Swagger'da test ediliyor

[ ] Ana repo guncel, merge sonrasi build basarili

Sprint 4

Faz 3: Islemler -- "Uctan Uca Akis"

27 Nisan (Pzt) - 03 Mayis (Paz) | Kapasite: 45-60 kisi-saat

Bu sprint sonunda kullanici kayit -> giris -> otel ara -> detay gor -> rezervasyon yap -> yorum yaz akisini uctan uca yapabilmeli. En kritik entegrasyon sprinti.

Grup A: Admin Backend + Sayfalar + Logger Entegrasyon (~15-20 saat)

  • API: AdminController -- E36 (dashboard istatistikleri), E37 (kullanici listesi), E38 (status), E39 (rol)
  • API: AdminController -- E44 (log listesi), E45 (log detayi) -- Singleton Logger endpoint'leri
  • Logger: Tum controller'lara log cagrilari ekle (~15 log noktasi: Auth, Hotels, Reservations, Reviews, Admin)
  • MVC: Admin/DashboardController -- Dashboard.cshtml (istatistik kartlari)
  • MVC: Admin/UserMgmtController -- Users.cshtml (kullanici listesi + aktif/pasif + rol degistir)
  • MVC: Admin/LogController -- Logs.cshtml (sistem loglari: seviye/tarih filtre, sayfalama, detay modal)
  • MVC: HomeController -- About.cshtml (hakkimizda - statik)
  • Test: Admin girisi -> dashboard -> kullanici yonetimi -> log goruntuleme akisi

Grup B: Admin Otel Yonetimi + Entegrasyon (~15-20 saat)

  • MVC: Admin/HotelMgmtController -- Hotels.cshtml (otel listesi + yeni ekle + sil)
  • MVC: Admin/HotelMgmtController -- HotelEdit.cshtml (otel duzenleme: bilgi + gorsel yukle + olanak ata)
  • MVC: Admin/AmenityController -- Amenities.cshtml (olanak listesi + ekle)
  • MVC: HomeController -- Contact.cshtml (iletisim - statik)
  • Entegrasyon: Otel Detay sayfasina oda listesi + yorum bolumu + gorsel galeriyi entegre et

Grup C: Kullanici Islem Sayfalari (~15-20 saat)

  • MVC: BookingController -- _BookingModal.cshtml (rezervasyon formu - otel detay icinde)
  • MVC: ReservationsController -- My.cshtml (rezervasyonlarim listesi + iptal butonu)
  • MVC: ReservationsController -- Detail.cshtml (rezervasyon detay + fatura goruntule)
  • MVC: ReviewsController -- My.cshtml (yorumlarim listesi + silme)
  • Partial: _BookingModal.cshtml, _ReviewCard.cshtml, _RoomCard.cshtml
  • API: AdminController (E40 - tum rezervasyonlar, E41 - durum degistir)

Milestone 4 -- Sprint 4 Bitis Kriteri (03 Mayis) -- EN KRITIK MILESTONE

[ ] Admin paneli calisiyor: dashboard + kullanici yonetimi + otel CRUD

Sprint 5

Faz 4: Admin Tamamlama + Entegrasyon Testi

04 Mayis (Pzt) - 10 Mayis (Paz) | Kapasite: 45-60 kisi-saat

Eksik admin sayfalari tamamlanir, tum sayfalar arasi gecisler test edilir, bug'lar duzeltilir. Sprint sonunda proje fonksiyonel olarak tamamlanmis olmalidir.

Grup A: Email + Son Kontroller (~15-20 saat)

  • Email: Email dogrulama akisini uca bagla (Mailtrap/mock) veya yedek plani uygula
  • "Beni Hatirla" ozelligini Login sayfasinda implement et
  • Hesap kilitleme mantigi (FailedLoginAttempts, LockoutEndTime) son kontrol
  • Bug fix: Auth akisinda bulunan hatalari duzelt
  • Cross-test: Diger gruplarin auth gerektiren sayfalarini test et

Grup B: Otel Detay Entegrasyon + Polish (~15-20 saat)

  • Entegrasyon: Otel Detay sayfasinda tum partial view'larin dogru render oldugunu dogrula
  • Gorsel: Gorsel galeri davranisi (carousel/lightbox) polish
  • Responsive: Ana sayfa, arama, otel detay sayfalarinda responsive kontrol
  • Bug fix: Arama/filtreleme/siralama hatalarini duzelt
  • Seed data: Yeterli test verisi oldugunu dogrula (en az 10 otel, gorseller, olanaklar)

Grup C: Admin Islem + Kalan Sayfalar (~15-20 saat)

  • MVC: Admin/RoomTypeController -- RoomTypes.cshtml (oda tipi listesi + ekle + duzenle)
  • MVC: Admin/ReservationMgmtController -- Reservations.cshtml (tum rezervasyonlar + durum degistir)
  • MVC: HomeController -- Faq.cshtml (SSS - statik, accordion)
  • Bug fix: Rezervasyon ve yorum akisindaki hatalari duzelt
  • Cross-test: Fatura goruntuleme, iptal senaryolari

Ortak (3 Kisi Birlikte)

  • Entegrasyon testi: Tum akislari uctan uca kontrol et (kayit, giris, arama, rezervasyon, yorum, admin)
  • PR review: Tum acik PR'lari kapat, takim branch'lerinden dev'e merge et; stabil surumu main'e hazirla
  • Build kontrolu: Clean build, hata yok, uyari minimum

09. Tampon Sureler ve Onemli Notlar

Yerlesik Tampon

  • Sprint 5 (1 tam hafta): Entegrasyon + bug fix icin ayrilmis tampon. Eger Sprint 2-4'te gecikme olursa, Sprint 5'te telafi edilir.
  • Sprint 6 (4 gun): Sadece polish. Fonksiyonel eksik varsa burada tamamlanir.
  • Toplam tampon: ~11 gun (Sprint 5 + Sprint 6). Bu, toplam surenin %27'si demektir -- saglikli bir oran.

Kesilecek Ozellikler (Gerekirse)

Zaman yetmezse asagidaki ozellikler MVP'den cikarilabilir (oncelik sirasina gore):

  • 1. Email dogrulama: IsEmailVerified = true default yapilir, kayit -> dogrudan giris
  • 2. Fatura goruntuleme: Rezervasyon detay yeterli, ayri fatura sayfasi olmayabilir
  • 3. Hesap kilitleme: FailedLoginAttempts mantigi sonraya birakilabilir
  • 4. "Beni Hatirla": Session-based auth yeterli olabilir
  • 5. FAQ sayfasi: Statik sayfa, son anda eklenebilir

Haftalik Rutinler

  • Pazartesi: Sprint planlama (15 dk) -- haftanin hedefleri, Trello guncelleme
  • Carsamba: Ara kontrol (10 dk) -- tikanma var mi? Yardim lazim mi?
  • Cuma: Sprint review (20 dk) -- ne tamamlandi, demo, PR review
  • Her gun: Kisa stand-up (5 dk) -- dun ne yaptim, bugun ne yapacagim, engelim var mi?

Grup Atamalari Hakkinda

Grup atamalari netlesti: Grup A Alper, Grup B Hilal, Grup C Sevde.

  • Grup A - Alper (Kimlik + Yonetim + Logger): En karmasik is mantigi (JWT, BCrypt, Email) + Singleton Logger pattern (design pattern sorumlulugu). Deneyimli veya ogrenmeye istekli kisi icin uygun.
  • Grup B - Hilal (Otel Vitrin): En fazla endpoint ama standart CRUD. Frontend agirlikli, gorsel zengin sayfalar.
  • Grup C - Sevde (Islemler): SP/Trigger/View ile DB yogun. Rezervasyon is mantigi karmasik ama kalipsal.
